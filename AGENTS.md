# Working on Astro Worker

Use the Flutter version in `.flutter-version`. Run `scripts/check.sh` before submitting changes. Keep calculations offline and deterministic and use fixed instants in tests. Keep UTC in the domain and convert at presentation boundaries. Treat traditional interpretations as editorial content. Use original or appropriately licensed assets. See [architecture](docs/architecture/overview.md) and [release acceptance](docs/testing/release-acceptance.md). Keep the GitHub backlog open until its acceptance criteria are verified.
