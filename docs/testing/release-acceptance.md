# Release acceptance

| Gate | Evidence required |
| --- | --- |
| Accuracy | Independent per-observable fixtures and five-platform parity with documented tolerances |
| Offline and privacy | Offline reload and upgrade, no outbound personal data, purge and migration tests |
| Accessibility | Keyboard, text scaling, screen readers, contrast and responsive orientation |
| Native widgets | Hardware placement, refresh, stale data and deep-link checks for each supported target |
| Distribution | Platform identifiers verified, notices and source obligations satisfied, signing and per-channel smoke tests complete |
| Performance | Device startup, calendar interaction, battery and storage measurements |

Keep the open [release milestone](https://github.com/repasscloud/astro-worker/milestone/8) current. Successful debug builds and unit tests qualify development progress; release approval requires the evidence above.
