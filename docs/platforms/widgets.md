# Platform widgets

Android uses AppWidgetProvider with remote views or Glance after evaluation. iOS and macOS require distinct WidgetKit targets, App Group sharing and system-managed timelines. Windows Widgets Board needs host capability and packaging investigation. Web supports the app dashboard with install and offline caching through a manifest and service worker.

The app presently supports Moon and universal-day previews. The planned catalogue, size families and local notifications are specified in the product requirements. Native installation, timeline refresh and OS-specific verification remain tracked per platform in the [widget milestone](https://github.com/repasscloud/astro-worker/milestone/5).
