# ADR 0001 — Use a replaceable pure-Dart ephemeris for the foundation

Accepted for foundation development. Adopt Astronomia behind `AstronomyEngine` for one offline calculation path across the target platforms. Validate its results independently and preserve a provider boundary for future replacement or higher-accuracy resources. Review Swiss Ephemeris separately with the project owner. See the [ephemeris decision](../calculations/ephemeris.md).
