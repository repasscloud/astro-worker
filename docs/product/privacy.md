# Privacy

The app calculates astronomy and selects editorial content on the device. The baseline has no accounts, analytics, advertising or background transmission. The optional birth date is local and can be removed in Settings. The app stores display timezone and preferences. Optional manually entered observer coordinates stay in local preferences and can be cleared in Settings. Android requests precise location only if you choose Use device GPS. The app uses the GPS provider without sending your position to a service, and only saves it when you confirm the coordinates. Browser deployment fetches its own static app resources and may create standard server access logs.

Birth chart profiles are optional and stored locally. Deleting a profile removes its name, birth date, optional time and location from local settings. Keep personal values out of widget snapshots by default, avoid logging them, and document storage, backup and deletion behaviour before releasing.

Settings backup copies a versioned JSON document to the clipboard on request. It excludes birth records and observer coordinates by default. If you choose to include them, treat the copied text as personal data. Astro Worker never reads the clipboard in the background. Restore validates the pasted document before writing settings and preserves existing personal records when the backup excludes them. Reset removes app preferences and both optional personal records. The app migrates legacy settings to a single local record and removes the old copies.
