# Roadmap

See [GitHub milestones](https://github.com/repasscloud/astro-worker/milestones) and the [issue catalogue](../../scripts/backlog.tsv).

| Milestone | Initial status |
| --- | --- |
| 0 Project Foundation | Five runners, documentation, CI and project management established. |
| 1 Astronomical Calculation Engine | Pure-Dart engine, initial reference fixtures and manual observer horizon events implemented. Full-range qualification, extra bodies, location permissions and resource work open. |
| 2 Core Application | Nine destinations, positions, active aspects and calculated event lists implemented. Event-solving and sidereal support open. |
| 3 Numerology and Spiritual Content | Universal and personal numbers, master numbers and versioned English editorial content implemented. Localisation and content expansion open. |
| 4 Native Widgets | Snapshot contract and previews established. Native integration remains open independently by platform. |
| 5 Notifications and Calendar Integration | Local scheduling and calendar export tracked independently. |
| 6 Personal Astrology | Deferred birth profiles, natal charts, houses, transits and relationship charts. |
| 7 Cross-Platform Quality and Release | Accessibility, privacy, performance, signing and per-platform acceptance remain open. |

The [owner approved AGPL-3.0 and Swiss Ephemeris](https://github.com/repasscloud/astro-worker/issues/1). Source, self-builds and web access are free. Planned one-time purchases are AUD $4.99 on Android and iOS and AUD $7.99 on macOS and Windows, subject to channel clearance. Core development can proceed with the current provider. Full release accuracy remains an [open gate](https://github.com/repasscloud/astro-worker/issues/3).
