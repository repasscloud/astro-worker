# Astro Worker

Astro Worker is an offline-first Flutter application for Sisters with Mirrors. It separates calculated astronomy from traditional astrology, numerology and spiritual content.

See [setup](docs/development/setup.md), [product requirements](docs/product/requirements.md), [roadmap](docs/product/roadmap.md) and [platform status](docs/platforms/compatibility.md).
